# Marketing SEO Brief

A skill that turns a target query and the pages that rank for it into a
writer's brief, with the standards of an SEO specialist and a content
editor, in one pass.

## What you get

- The search intent, with the results it is based on.
- A review of each top page and what they all miss.
- An outline with what each section must cover, the questions to
  answer, and a meta description draft.

## Configuring

Give the target query and paste the search results or competitor pages.
Add keyword data from your own tool if you want volumes in the brief; it
never makes them up.
