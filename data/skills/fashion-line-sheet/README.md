# Fashion Line Sheet

A skill that writes a label's wholesale selling papers with the
standards of showroom sales support, in one pass: papers buyers skim
mid-appointment, with facts before adjectives and nothing invented.

## What you get

- Line-sheet copy, three to five lines per style.
- A price list table (style, colorways, wholesale, MSRP, MOQ) and one
  cutoff and delivery block per window.
- Order-form text listing what the buyer must state.
- Follow-up email drafts per buyer, cutoff restated.

## Configuring

Give the style list with exact wholesale and MSRP, minimums, size runs,
colorways and delivery windows. If you only have price ranges, it asks
for the exact prices. Add meeting notes to get follow-ups.
