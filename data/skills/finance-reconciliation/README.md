# Finance Reconciliation

A skill that reconciles one account for one period with the standards
of a bookkeeper, in one pass.

## What you get

- A match report that foots: opening and closing balances, matched
  totals, and any remaining difference stated exactly.
- An exception list with the likely cause per item: timing, missing
  entry, duplicate, miscoded or bank error.
- Draft correcting journal entries, one per correction, with the source
  line named.

## Configuring

Paste the statement export and the ledger export, and name the account
and period. Say what you already know (deposits in transit, pending
charges). Nothing is posted; you enter the journal entries.
