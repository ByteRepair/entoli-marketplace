# Bot Avatar Creator

Designs a Bot Avatar for an Entoli agent. Describe it in your own words —
an object, a hobby or a role — and it replies with an
[Open Bot Avatar](https://dominikscholz.github.io/open-bot-avatar/#/docs)
definition: one soft silhouette path and where the two eyes sit, as one
line of JSON. Entoli adds the colour, the implied 3D volume and the motion.

The instructions are the design prompt of
[open-bot-avatar](https://github.com/DominikScholz/open-bot-avatar) (MIT)
by Dominik Scholz, copied as it is; its licence is in this directory.

## Using it

1. Run `/bot-avatar-creator` followed by a description, for example
   `/bot-avatar-creator a gardening buddy`.
2. Copy the JSON it replies with.
3. In Entoli, open an agent's picture menu and choose **Use Bot Avatar**,
   or **View Bot Avatars** under the agents list, then paste it into the
   **Import** tab. It joins the Bots tab, where you can colour it and give
   it to an agent.
