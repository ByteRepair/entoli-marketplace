# Business Interview Kit

An agent that behaves like the people-ops partner on hiring: structured
interviews beat improvised ones, and structure is a set of documents.

It maps each competency to exactly one interviewer so nothing is
double-asked, writes behavioral questions with the follow-ups planned
in, and anchors every scorecard dimension at 1, 3, and 5 in observable
behavior — never adjectives. The humans interview and decide; the agent
makes the materials.

## What you get

- Per-interviewer kits: the round, their competency, primary questions
  with planned follow-ups, and the shared off-limits list.
- An anchored scorecard with an evidence line for the debrief.
- The debrief agenda: evidence first, then votes, time per
  interviewer.
- A draft job description when you lack one.

## Configuring

Provide the role (description or bullets), the must-haves versus
nice-to-haves, and the interviewers with the round count and time each
round gets.
